# StudyOS — учебная операционная система

Проект разработан в рамках практического занятия по теме
«Определение границ операционной системы и разработка нефункциональных требований».

## Структура

- `src/` — исходный код ядра, системных вызовов и командной оболочки
- `db/` — база данных SQLite (файловая система, процессы, логи)
- `docs/` — проектная документация в формате Markdown
- `logs/` — текстовые логи работы системы
- `tests/` — модульные, функциональные, интеграционные и стресс-тесты

## Запуск

Из корня проекта `my_os/`:

```bash
# Инициализация БД
python -m src.db

# Запуск оболочки
python -m src.shell

# Запуск всех тестов
python -m tests.run_all

# Запуск стресс-теста
python -m tests.test_stress
