# My_os — учебная операционная система

Учебный проект по дисциплине «Осуществление интеграции программных модулей». Представляет собой симулятор операционной системы, реализованный на Python с использованием SQLite в качестве виртуального диска.

## Возможности

- **Управление пользователями:** регистрация, вход, роли (`admin`, `user`, `guest`), разграничение прав.
- **Файловая система:** создание, чтение, запись, удаление и просмотр списка файлов.
- **Управление процессами:** создание, планирование (Round-Robin), завершение.
- **Управление памятью:** выделение, освобождение, контроль лимита (1024 МБ).
- **Журналирование:** все системные вызовы записываются в таблицу `syscalls_log`.
- **Командная оболочка** с набором CLI-команд.

## Стек технологий

- Python 3.10+
- SQLite (встроенная в Python)
- VS Code
- Git

## Установка и запуск

```bash
# Клонирование
git clone <адрес репозитория>
cd my_os

# Инициализация базы данных
python -m src.db

# Запуск оболочки
python -m src.shell

# Запуск всех тестов
python -m tests.run_all

# Запуск стресс-теста
python -m tests.test_stress
```

Если Python не в PATH (Windows), используйте `uv`:

```powershell
uv run python -m src.db
uv run python -m src.shell
uv run python -m tests.run_all
```

## Команды оболочки

| Команда | Описание |
|---------|----------|
| `help` | Список доступных команд |
| `whoami` | Текущий пользователь |
| `login` | Войти в систему |
| `logout` | Выйти из системы |
| `create` | Создать файл (запросит путь и содержимое) |
| `cat <path>` | Прочитать файл |
| `ls [prefix]` | Список файлов |
| `delete <path>` | Удалить файл |
| `run <app> [MB]` | Запустить процесс |
| `ps` | Список процессов |
| `kill <pid>` | Завершить процесс |
| `mem` | Статистика памяти |
| `logs` | Журнал системных вызовов |
| `exit` | Завершить работу ОС |
