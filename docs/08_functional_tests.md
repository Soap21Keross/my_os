# Функциональные тесты

## Модуль fs.py
Функции модуля: create_file, read_file, write_file, delete_file, list_files, get_owner, get_file_info, copy_file.

### FT-01: create_file создаёт файл
- **Предусловие:** файла с указанным путём нет.
- **Шаги:** вызвать `create_file('/ft01.txt', 'content', 'admin')`.
- **Ожидаемый результат:** возвращено число > 0, в таблице files появилась запись.

### FT-02: create_file отклоняет дубликат
- **Предусловие:** файл `/ft02.txt` уже создан.
- **Шаги:** повторно вызвать `create_file('/ft02.txt', 'other', 'admin')`.
- **Ожидаемый результат:** возвращено `-1`.

### FT-03: read_file возвращает содержимое
- **Предусловие:** файл `/ft03.txt` с содержимым `'hello'`.
- **Шаги:** вызвать `read_file('/ft03.txt')`.
- **Ожидаемый результат:** возвращена строка `'hello'`.

### FT-04: read_file возвращает пустую строку для несуществующего файла
- **Предусловие:** файла `/missing.txt` нет.
- **Шаги:** вызвать `read_file('/missing.txt')`.
- **Ожидаемый результат:** возвращена пустая строка.

### FT-05: write_file обновляет содержимое
- **Предусловие:** файл `/ft05.txt` с содержимым `'old'`.
- **Шаги:** вызвать `write_file('/ft05.txt', 'new')`, затем `read_file('/ft05.txt')`.
- **Ожидаемый результат:** возвращена строка `'new'`.

### FT-06: delete_file удаляет файл
- **Предусловие:** файл `/ft06.txt` создан.
- **Шаги:** вызвать `delete_file('/ft06.txt')`, затем `read_file('/ft06.txt')`.
- **Ожидаемый результат:** `read_file` возвращает пустую строку.

### FT-07: list_files возвращает список по префиксу
- **Предусловие:** созданы файлы `/ft07_a.txt` и `/ft07_b.txt`.
- **Шаги:** вызвать `list_files('/ft07')`.
- **Ожидаемый результат:** список содержит оба файла.

### FT-08: get_owner возвращает владельца
- **Предусловие:** файл `/ft08.txt` создан с владельцем `'admin'`.
- **Шаги:** вызвать `get_owner('/ft08.txt')`.
- **Ожидаемый результат:** возвращена строка `'admin'`.

### FT-09: get_owner возвращает None для несуществующего файла
- **Предусловие:** файла `/missing2.txt` нет.
- **Шаги:** вызвать `get_owner('/missing2.txt')`.
- **Ожидаемый результат:** возвращено `None`.

### FT-10: get_file_info возвращает полную информацию
- **Предусловие:** файл `/ft09.txt` создан с владельцем `'admin'`.
- **Шаги:** вызвать `get_file_info('/ft09.txt')`.
- **Ожидаемый результат:** словарь с ключами `path`, `content`, `owner`, `created_at`.

### FT-11: copy_file копирует содержимое (доп. задание)
- **Предусловие:** файл-источник `/src.txt` с содержимым `'data'` существует.
- **Шаги:** вызвать `copy_file('/src.txt', '/dst.txt', 'admin')`.
- **Ожидаемый результат:** возвращён id > 0, `read_file('/dst.txt')` возвращает `'data'`.

### FT-12: copy_file отклоняет существующий приёмник
- **Предусловие:** файлы `/src.txt` и `/dst.txt` существуют.
- **Шаги:** вызвать `copy_file('/src.txt', '/dst.txt', 'admin')`.
- **Ожидаемый результат:** возвращено `-1`.

## Модуль scheduler.py
Функции модуля: create_process, list_processes, get_process, terminate_process, schedule_round_robin, process_count, schedule_fcfs.

### FT-13: create_process создаёт процесс
- **Предусловие:** памяти достаточно.
- **Шаги:** вызвать `create_process('ft_app', 'admin', 10)`.
- **Ожидаемый результат:** возвращён PID > 0, в таблице processes появилась запись.

### FT-14: create_process отклоняет процесс при переполнении памяти
- **Предусловие:** памяти недостаточно.
- **Шаги:** вызвать `create_process('huge', 'admin', 5000)`.
- **Ожидаемый результат:** возвращено `-1`.

### FT-15: list_processes возвращает все процессы
- **Предусловие:** созданы два процесса.
- **Шаги:** вызвать `list_processes()`.
- **Ожидаемый результат:** список из двух записей.

### FT-16: get_process находит процесс по PID
- **Предусловие:** процесс с PID создан.
- **Шаги:** вызвать `get_process(pid)`.
- **Ожидаемый результат:** словарь с полями процесса.

### FT-17: get_process возвращает None для несуществующего PID
- **Предусловие:** PID 99999 не существует.
- **Шаги:** вызвать `get_process(99999)`.
- **Ожидаемый результат:** `None`.

### FT-18: terminate_process завершает процесс и освобождает память
- **Предусловие:** процесс с PID создан, память выделена.
- **Шаги:** запомнить `memory_used`, вызвать `terminate_process(pid)`.
- **Ожидаемый результат:** `True`, память уменьшилась на размер процесса.

### FT-19: terminate_process возвращает False для несуществующего PID
- **Предусловие:** PID 99999 не существует.
- **Шаги:** вызвать `terminate_process(99999)`.
- **Ожидаемый результат:** `False`.

### FT-20: schedule_round_robin выбирает процесс
- **Предусловие:** созданы два процесса в состоянии `ready`.
- **Шаги:** вызвать `schedule_round_robin()`.
- **Ожидаемый результат:** возвращён процесс в состоянии `running`.

### FT-21: schedule_fcfs выбирает первый по времени процесс (доп. задание)
- **Предусловие:** созданы процессы p1 (раньше) и p2 (позже).
- **Шаги:** вызвать `schedule_fcfs()`.
- **Ожидаемый результат:** выбран p1 (наименьший `created_at`).

### FT-22: process_count возвращает количество процессов
- **Предусловие:** созданы три процесса.
- **Шаги:** вызвать `process_count()`.
- **Ожидаемый результат:** `3`.

## Модуль syscalls.py
Функции модуля: sys_login, sys_logout, sys_whoami, sys_create_file, sys_read_file, sys_delete_file, sys_list_files, sys_exec, sys_ps, sys_kill, sys_mem_alloc, sys_logs, sys_shutdown.

### FT-23: sys_login логирует успешный вход
- **Предусловие:** пользователь `st_admin` зарегистрирован.
- **Шаги:** вызвать `sys_login('st_admin', 'secret123')`.
- **Ожидаемый результат:** `True`, запись в `syscalls_log` со статусом `OK`.

### FT-24: sys_login отклоняет неверный пароль
- **Предусловие:** пользователь `st_admin` зарегистрирован.
- **Шаги:** вызвать `sys_login('st_admin', 'wrong')`.
- **Ожидаемый результат:** `False`, запись в `syscalls_log` со статусом `DENIED`.

### FT-25: sys_create_file логируется
- **Предусловие:** пользователь авторизован.
- **Шаги:** вызвать `sys_create_file('/st01.txt', 'x', 'st_admin')`.
- **Ожидаемый результат:** id > 0, количество записей `sys_create_file` в логе увеличилось на 1.

### FT-26: sys_delete_file запрещает удаление чужого файла
- **Предусловие:** файл `/st03.txt` принадлежит `st_admin`.
- **Шаги:** вызвать `sys_delete_file('/st03.txt', 'st_user')`.
- **Ожидаемый результат:** `False`, запись в `syscalls_log` со статусом `DENIED`.

### FT-27: sys_exec логируется и создаёт процесс
- **Предусловие:** память доступна.
- **Шаги:** вызвать `sys_exec('st_app', 'st_admin')`.
- **Ожидаемый результат:** PID > 0, запись в `syscalls_log` со статусом `OK`.

### FT-28: sys_kill запрещён обычному пользователю
- **Предусловие:** процесс создан администратором.
- **Шаги:** вызвать `sys_kill(pid, 'st_user')`.
- **Ожидаемый результат:** `False`, статус `DENIED`.

### FT-29: sys_kill разрешён администратору
- **Предусловие:** процесс создан.
- **Шаги:** вызвать `sys_kill(pid, 'st_admin')`.
- **Ожидаемый результат:** `True`.

### FT-30: sys_logs возвращает список
- **Предусловие:** система работала, есть записи в журнале.
- **Шаги:** вызвать `sys_logs(10, 'st_admin')`.
- **Ожидаемый результат:** список записей.

### FT-31: sys_mem_alloc отклоняет превышение лимита
- **Предусловие:** свободной памяти меньше запрошенного объёма.
- **Шаги:** вызвать `sys_mem_alloc(99999, 'admin')`.
- **Ожидаемый результат:** `False`, статус `NO_MEMORY`.
